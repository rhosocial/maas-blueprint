# 第 21 章 图像数据面

> 图像是"短任务"：几秒到几十秒。它既能同步返回，也能异步，选择取决于你能接受多长的连接。

## 21.1 同步还是异步

| 耗时 | 建议 | 理由 |
|---|---|---|
| < 5 秒 | 同步 | 客户端等待可接受 |
| 5~30 秒 | 同步 + 较长超时，或短异步 | 取决于网关超时 |
| 30 秒~数分钟 | 异步任务 | 连接不可靠，需可追踪 |
| 批量（>10 张） | 异步任务 | 总时长不可控 |

〔建议〕**默认同步上限 30 秒；超过走异步任务接口（与视频共用任务系统）。**
这样客户只有两套调用方式，不用为图像单独学一套。

## 21.2 参数与成本映射

| 参数 | 影响 | 成本关系 |
|---|---|---|
| 分辨率 | 像素数 | 近似线性（甚至超线性） |
| 步数（steps） | 去噪迭代 | 线性 |
| 质量档 | 步数 + 精修 | 档位定价 |
| 批量 n | 张数 | 线性 |
| 参考图（img2img） | 额外编码 | 少量 |
| 高清修复 | 二次生成 | 显著 |

成本表要按"档位"呈现，而不是让客户理解步数：

| 档位 | 分辨率 | 步数 | 相对成本 |
|---|---|---|---|
| `standard` | 1024×1024 | 20 | 1.0 |
| `high` | 1024×1024 | 40 | 1.8 |
| `ultra` | 2048×2048 | 40 | 6.5 |

## 21.3 接口形态

```
POST /v1/images/generations
{
  "model": "image-pro",
  "prompt": "...",
  "size": "1024x1024",
  "quality": "standard",
  "n": 1,
  "seed": 12345,
  "response_format": "url"   // url | b64_json
}
```

响应：

```json
{
  "created": 1760000000,
  "data": [
    {"url": "https://...", "revised_prompt": "...", "seed": 12345}
  ],
  "usage": {"images": 1, "size": "1024x1024", "quality": "standard"}
}
```

三个约定：

1. **返回 seed**，便于复现；相同 seed + 参数应得到相同结果（引擎支持时）。
2. **返回 `revised_prompt`**（若做了提示词改写），否则客户不知道实际生成了什么。
3. **URL 有 TTL**（如 24 小时），并在文档中写明；长期存储由客户自己转存。

## 21.4 批量与部分成功

`n > 1` 时，可能部分成功（例如 4 张中 1 张被审核拒绝）。两种语义：

| 语义 | 行为 | 适用 |
|---|---|---|
| 全有或全无 | 任一张失败则整体失败 | 简单，但浪费 |
| 部分成功 | 返回成功的图 + 失败原因 | 批量场景 |

〔建议〕**批量用部分成功**，并在 `usage` 里按实际生成张数计量。文档要写清"失败张数不收费"。

## 21.5 内容安全与版权

| 风险 | 处理 |
|---|---|
| 违规内容 | 输入 prompt 审核 + 输出图审核 |
| 名人肖像 | 人脸识别 + 策略库 |
| 版权风格 | 关键词/风格库 + 人工复核通道 |
| 参考图侵权 | 上传时声明 + 抽检 |
| 未标识 | 强制隐式标识 + 默认显式水印 |

图像审核可以同步做（秒级），但要注意：**审核拒绝也是成本**，不能免费无限重试。

## 21.6 容量与队列

- 容量单位：**张/小时**（按档位分别统计）。
- 弹性指标：队列长度 + 预计等待时间。
- 单张任务短，所以可以激进扩容；但冷启动仍然以分钟计，需保留最小副本。

## 21.7 常见故障

| 故障 | 原因 | 处理 |
|---|---|---|
| OOM | 高分辨率 + 大 batch | 按档位限制 batch |
| 超时 | 步数过高 | 设置单张上限 |
| 输出全黑/噪声 | 权重损坏 | 哈希校验 + 回滚 |
| 审核误杀 | 策略过严 | 人工复审 + 白名单 |
| URL 失效 | TTL 太短 | 文档写明 + 支持转存 |

## 本章结论

- 图像默认同步 30 秒，超过走异步任务，与视频共用任务系统。
- 成本按档位呈现，不暴露步数细节。
- 批量用部分成功语义，按实际生成计量。
- 审核与标识是硬要求，不能为了体验绕过。

## 决策点（结合自身情况）

1. 同步上限 30 秒是否合适？取决于网关与客户端超时。
2. 是否支持 `b64_json`？会增加带宽与内存压力。
3. 版权风格策略由谁维护？
