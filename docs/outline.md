# 章节速览

> 本文件是全书章节的速览表：每章要点、交付物与验收线索。
> 正文以各章为准；本文件用于快速定位和检查覆盖度。

## 编写约定（贡献者参考）

- 每章结构固定：开篇结论 → 问题 → 设计 → 取舍 → 本章结论 → 决策点。
- 每章 1 张主图（Mermaid 或表格），不超过 2 张；图必须能独立看懂。
- 所有数字标注来源等级：`〔建议〕` / `〔通行〕` / `〔核验〕`。
- 不做产品评测式的横向对比，除非结论会改变选型；选型章只给"判据 + 当前选择 + 复核时点"。
- 每章末尾列 1~3 个决策点，供读者结合自身情况拍板。

## 第〇篇 前言

**00 前言：这本书怎么用**
- 读者、三条阅读路径、事实分级。
- 本书不写什么：不写 K8s 入门、不写 vLLM 源码解析、不写商务合同模板。
- 交付物：无。

## 第一篇 定位与约束

**01 MaaS 是什么、不是什么**
- 三层定义：算力底座 / 推理平台 / 产品化运营。
- 与 IaaS、PaaS、模型托管、API 转售的边界。
- 自建 vs 云上托管的决策矩阵（控制力、单位成本、合规、时间）。
- 成功判据：能跑、能交付、能卖、能算账、能过审。
- 交付物：一页纸定位声明。

**02 三类负载与两种时间尺度**
- 训练 / 在线推理 / 离线批处理的时间尺度差异（天-小时-秒-毫秒）。
- LLM / 图像 / 视频的六维画像表。
- 两种调度原子：训练作业（Gang）与推理副本（跨卡/跨机）。
- 为什么必须分池；可借卡的三个边界条件。
- 交付物：资源池拓扑初稿（4 池 + 1 共享通道）。

**03 单位经济学：一张卡能卖多少钱**
- 成本项：卡时、网络、存储、出网、审核算力、人力、合规。
- 公式：单位成本 = 卡时成本 ÷ 有效吞吐；毛利率与保本点。
- 三种计价单位（token / 张 / 秒）与四种售卖形态（按量、承诺、预留、批价）。
- 示例测算（示意数字，非报价）。
- 定价陷阱：缓存命中、失败重试、长上下文、免费额度、退款。
- 交付物：单位经济模型表（待填真实成本）。

**04 合规是架构约束，不是上线前的手续**
- 自研 = 备案主体；算法备案 + 大模型备案的分工〔核验〕。
- 生成合成内容标识：显式 / 隐式，写入点必须在管线末端。
- 内容安全审核：输入、输出、多模态。
- 日志留存与审计；下游客户责任划分。
- 工程含义清单（哪些字段、哪些开关、哪些日志是强制的）。
- 交付物：合规需求 → 架构约束映射表。

**05 总体架构：一个控制面，多个数据面**
- 分层图与组件职责表。
- 三条调用路径：同步、SSE 流式、异步任务。
- 控制面 / 数据面 / 状态面的划分；避免把任务状态放进推理实例。
- 八个关键架构决策（候选 ADR）。
- 失败域与降级边界。
- 交付物：架构图 v1 + 组件清单。

## 第二篇 基础设施

**06 集群、网络与存储**
- GPU 机型与拓扑（单机 8 卡、NVLink/NVSwitch、跨机 IB/RoCE）。
- 参数面 / 存储面 / 管理面三网分离；RDMA 的运维代价。
- 存储分层：镜像仓库、模型仓库、本地 NVMe 缓存、对象存储。
- 多集群与地域：什么时候必须拆集群。
- 交付物：集群规格书 v1。

**07 节点验收与基准测试**
- 上架前 burn-in：GPU 压测、显存 ECC、NVLink、IB 误码、NCCL all-reduce。
- 验收基线：单机带宽、跨机带宽、存储吞吐、镜像拉取时间。
- 定期巡检与"修好再上线"的回归门槛。
- 交付物：节点验收脚本清单 + 通过标准。

**08 资源模型、配额与优先级**
- K8s 资源抽象：`nvidia.com/gpu`、MIG、扩展资源、DRA 的取舍。
- 配额三层：租户 / 项目 / 队列；配额与容量的关系。
- 优先级类与抢占：谁可以抢谁、抢占的代价。
- 命名空间与隔离边界（不是安全边界）。
- 交付物：ResourceQuota / PriorityClass 设计表。

**09 权重、镜像与制品分发**
- 大权重分发：P2P、节点本地缓存、预热 DaemonSet。
- 镜像标准化：CUDA / 驱动 / 引擎版本矩阵。
- 模型制品：哈希、签名、许可证元数据。
- 冷启动时间预算的拆解（拉镜像 / 拉权重 / 初始化 / 编译 / 预热）。
- 交付物：制品分发方案 + 冷启动预算表。

## 第三篇 训练底座

**10 调度：Gang、队列与拓扑**
- 为什么默认调度器不适合训练：逐 Pod 调度导致死等。
- Gang 语义的最小实现与现成方案。
- 队列、公平性、DRF；配额与借还。
- 拓扑感知：机内 NVLink、机架、IB 域。
- 交付物：调度策略表（队列 × 优先级 × 抢占）。

**11 弹性、抢占与 checkpoint**
- 弹性训练的两个前提：可恢复、可缩容。
- checkpoint 策略：周期、异步、分片、保留代数。
- 抢占感知：先 checkpoint 再退出，或只在安全点抢占。
- 恢复时间目标（RTO）与" checkpoint 间隔 × 故障率"的关系。
- 交付物：checkpoint 规范 + 抢占协议。

**12 故障闭环与慢节点**
- 故障分类：硬故障、软故障、性能故障、配置漂移。
- 检测信号：XID、ECC、DCGM、链路抖动、NCCL 巡检。
- 隔离：cordon + taint + 自动工单；维修后的验收回归。
- 慢节点：识别方法与处理策略（不只看 loss）。
- 交付物：故障闭环状态机 + 值班手册目录。

**13 训练可观测与潮汐混部**
- 指标：MFU、SM Active、通信占比、数据加载等待。
- 归因：按任务、团队、用户；与配额/计费打通。
- 潮汐：推理低谷借卡给训练/批处理；抢回策略。
- 混部的三条红线（SLO、显存、网络）。
- 交付物：混部准入条件与回收流程。

## 第四篇 推理平台

**14 部署规格：从 profiling 到规格卡**
- 训练资源 ≠ 推理资源（显存构成不同）。
- 规格卡字段：精度、并行、最小卡数、最大上下文、并发、TTFT/TPOT、吞吐。
- 副本是调度原子；跨机副本与 LeaderWorkerSet。
- 规格与容量的关系：副本数 = f(QPS, SLO)。
- 交付物：部署规格卡模板（附录 B）。

**15 引擎选型与自研架构适配**
- 引擎判据：架构覆盖、量化、前缀缓存、LoRA、可观测、许可。
- vLLM / SGLang / TensorRT-LLM 的适用面〔通行〕。
- 自研架构适配的三条路：上游 PR、插件、fork；成本对比。
- 多模态与扩散引擎的成熟度差异。
- 交付物：引擎选型 ADR + 适配工作量估算。

**16 路由：缓存感知与队列感知**
- 轮询为什么错：前缀缓存命中率与队列深度。
- 会话粘性、缓存哈希、租户隔离的冲突。
- Gateway API Inference Extension / EPP 的角色〔核验〕。
- 网关七件事：鉴权、限流、路由、重试、超时、计量、审计。
- 交付物：路由策略表 + 网关职责边界。

**17 PD 分离与 KV 缓存分层**
- Prefill / Decode 的资源画像差异。
- 收益条件：长 prompt、高并发、足够带宽；否则是负优化。
- KV 分层：HBM → 本地 DRAM/SSD → 远端；命中率度量。
- 压测方法：固定 SLA 下的单位 token 成本对比。
- 交付物：是否上 PD 的决策树。

**18 弹性、冷启动与发布治理**
- 弹性指标：并发、队列深度、KV 使用率、TTFT，而不是 GPU-Util。
- 冷启动预算与预热：权重缓存、最小副本、扩容提前量。
- 缩容要慢：在途请求、缓存价值、抖动。
- 发布：灰度、金丝雀、回滚、原地升级、LoRA 多租。
- 交付物：HPA/KEDA 指标定义 + 发布 runbook。

**19 优雅退出与过载保护**
- SIGTERM 全链路：摘流量 → 等在途 → 退出。
- 流式连接的 grace period 估算方法。
- 排队上限、快速失败、降级、重试预算。
- 客户端断连传导到引擎。
- 交付物：退出时序图 + 过载策略表。

## 第五篇 多模态数据面

**20 LLM 数据面**
- OpenAI 兼容的最小集合与扩展字段。
- SSE 细节：缓冲、心跳、超时、断线续传。
- 工具调用、结构化输出、多模态输入。
- 错误码与可重试语义。
- 交付物：API 契约 v1（LLM）。

**21 图像数据面**
- 同步 / 短异步的边界（秒级 vs 十秒级）。
- 分辨率、步数、质量档与成本的映射。
- 批量出图与队列；版权与风格风险。
- 交付物：图像 API 契约 + 成本档位表。

**22 视频数据面**
- 为什么必须异步任务：分钟级、独占多卡、失败重算贵。
- 参数：时长、分辨率、帧率、音频、参考素材。
- 交付：预签名 URL、保留期、清理策略。
- 抢占边界：任务边界或阶段 checkpoint。
- 交付物：视频任务契约 + 容量单位定义。

**23 多模态理解与内容处理**
- 上传通道：对象存储直传，不走 base64。
- 抽帧、解码、转码的 CPU 预算。
- 编码器与 LLM 分离部署；内容哈希缓存。
- 长视频的分段与聚合策略。
- 交付物：媒体处理管线图。

## 第六篇 任务系统

**24 任务模型与状态机**
- 状态：queued / leased / running / succeeded / failed / canceled / expired。
- 幂等键、重试代数、超时、优先级、回调地址。
- 状态权威在中心，实例只上报进度。
- 交付物：状态机图 + 转换表。

**25 租约、拉取与背压**
- Worker pull 而非 master push：天然背压。
- 租约、心跳、续约、超时重入队。
- 按队列深度扩缩容；任务与副本的匹配（GPU 数、模态）。
- 交付物：租约协议 + 重试策略。

**26 交付、回调与对账**
- 先上传校验，再回调；回调至少一次。
- 签名、时间戳、防重放；接收方幂等。
- 主动查询兜底；对账任务。
- 交付物：回调契约 + 对账作业。

**27 计费联动：预扣、退款与幂等**
- 预扣（hold）→ 结算（capture）→ 退款（refund）。
- 失败、取消、超时、审核拒绝的口径。
- 与任务状态机的原子性；事件流水去重。
- 交付物：计费状态表 + 口径说明。

## 第七篇 产品化与运营

**28 模型目录与准入**
- 上架材料：权重来源、许可证、评估报告、性能基线。
- 部署规格与别名；灰度、回滚、退役。
- 质量回归：chat template、tokenizer、量化、工具解析。
- 交付物：上架 checklist + 目录数据模型。

**29 API 产品面与版本策略**
- 端点清单：models / chat / embeddings / images / videos / tasks / files。
- 版本策略：URL 版本、字段兼容、弃用周期。
- SDK 与错误码规范。
- 交付物：API 风格指南。

**30 身份、租户与密钥**
- 组织 / 项目 / 环境 / Key 四层。
- RBAC 与最小权限；Key 轮换与吊销。
- 租户隔离的四个面：数据、缓存、配额、日志。
- 交付物：权限矩阵。

**31 限流、公平与配额**
- 限流单位：RPM、TPM、并发、上下文长度、任务数。
- 令牌桶 / 漏桶 / 并发信号量；分层限流。
- 公平排队与防大客户挤占。
- 过载时的拒绝策略与 Retry-After。
- 交付物：限流规则表。

**32 计量、账单与 SLO**
- 计量事件：输入、输出、缓存命中、图像张数、视频秒数。
- 流式中断与重试的计量口径。
- 账单周期、对账、发票、争议处理。
- SLO：TTFT、TPOT、成功率、任务完成时长；状态页。
- 交付物：计量字典 + SLA 草案。

## 第八篇 安全与合规落地

**33 内容安全与多模态审核**
- 输入 / 输出 / 参考素材三端审核。
- 文本、图像、视频（抽帧 + 音频）的审核管线。
- 拒绝口径：是否计费、是否重试、是否人工复审。
- 专项策略：人脸、未成年人、版权、政治敏感。
- 交付物：审核策略矩阵 + 成本估算。

**34 生成内容标识与水印**
- 显式标识：位置、样式、默认开关、客户关闭的协议与日志。
- 隐式标识：元数据、水印、抗压缩/裁剪/转码测试。
- 标识与审核、备案材料的关系。
- 交付物：标识实现规范 + 测试用例。

**35 数据安全、缓存隔离与备案工程化**
- 日志脱敏、prompt 留存策略、删除请求。
- 前缀缓存的跨租户侧信道与隔离方案。
- 备案材料工程化：测试通道、题集、变更记录、抽检应对。
- 交付物：数据分类分级表 + 备案材料清单。

## 第九篇 运营与实施

**36 可观测体系与指标字典**
- 四层指标：基础设施 / 引擎 / 服务 / 业务。
- request_id 贯穿；租户与模型维度。
- GPU-Util 为什么不够；SM Active、MFU、通信占比。
- 告警分级与降噪。
- 交付物：指标字典（附录 D）。

**37 容量、成本与优化排序**
- 容量单位：token/s、张/小时、秒/小时。
- 预测、预留、潮汐、压测。
- 优化排序：引擎 > 路由 > 调度 > 硬件。
- 单位成本月报模板。
- 交付物：容量模型 + 优化 backlog。

**38 路线图：四阶段与验收标准**
- P0 合规与基础设施；P1 LLM 最小闭环；P2 图像与任务系统；P3 视频与规模化。
- 每阶段的交付物、验收、退出条件、不做什么。
- 与商务节奏的对齐（首个付费客户）。
- 交付物：路线图 + 里程碑。

**39 组织、风险与决策记录**
- 团队拓扑与职责（平台 / 引擎 / 产品 / SRE / 合规）。
- RACI 与值班。
- 风险登记：技术、合规、供应链、成本、人才。
- ADR 索引与决策点清单。
- 交付物：RACI 表 + 风险登记册。
